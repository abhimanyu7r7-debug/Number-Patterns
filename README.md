
# Number Patterns

A beginner-friendly C++ console program.

## Features
- Prints the multiplication table of a number.
- Prints a star pyramid of the chosen height.
- Uses loops and handles non-positive pyramid heights.

## How to Run
1. Compile main.cpp using a C++ compiler.
2. Run the compiled program.
3. Enter a number for the multiplication table.
4. Enter the pyramid height.

## Language
C++
